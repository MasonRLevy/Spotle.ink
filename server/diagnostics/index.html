TURN check

Run this on the device and network you will actually demo from. It asks each configured ICE server for candidates and reports what came back.

relay = a TURN server answered and will carry media when a direct path is impossible. This is the one that matters on locked-down wifi. srflx = STUN worked, so most networks will connect directly. host only = nothing external answered.

No relay anywhere means some pairs of players will silently fail to see each other. Fix by setting TURN_CREDENTIAL_URL (or TURN_URLS) on the server — see rtcConfig.ts.
